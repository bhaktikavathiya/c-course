# C Course

This repository documents my journey of learning C programming from scratch. It contains practice programs, exercises, and implementations of the concepts I learned while building a strong foundation in programming.

## Topics Covered

- Variables & Data Types
- Operators
- Input & Output
- Conditional Statements
- Loops
- Functions
- Arrays
- Strings
- Pointers
- Structures
- File Handling
- Dynamic Memory Allocation
- Memory Management

## Repository Structure

The repository is organized week by week. Each week contains the programs and exercises completed during that phase of learning, while the commits follow my day-by-day progress.

## Goal

The purpose of this repository is to:
- Strengthen my programming fundamentals.
- Practice core C concepts through code.
- Track my learning journey.
- Build clean and consistent coding habits.
